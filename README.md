# Midnight Graveyard Stroll

## Project Overview

Midnight Graveyard Stroll is a CSS-only Halloween environment created for the Haunted Harvest coding challenge. The project uses HTML5 and CSS3 to create an animated graveyard scene without JavaScript.

Users can navigate through three different graveyard scenes:

1. Graveyard Entrance
2. Haunted Graves
3. Deeper into the Graveyard

As the user moves through the scenes, the graveyard becomes darker and more active.

## Features

- Couple walking through the graveyard
- Black cat following behind the couple
- Ghost orbs floating and blinking
- Clouds drifting across a glowing full moon
- Ghosts appearing when gravestones are hovered or focused
- Cyclist passing through the graveyard
- Dead trees swaying in the wind
- Three CSS-only scene states using `:target`
- CSS keyframe animations
- Responsive layout using CSS Grid and Flexbox
- Keyboard-accessible navigation and gravestones
- Reduced-motion support with `prefers-reduced-motion`

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS custom properties
- CSS `:target`
- CSS `:hover` and `:focus`
- CSS `@keyframes`
- Git and GitHub

## Accessibility

The project includes visible keyboard focus indicators, keyboard-accessible interactive gravestones, readable color contrast, semantic HTML elements, and reduced-motion support.
